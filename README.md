# 汽车电子 · 前端 · CAN/UDS 诊断 学习仓库

## 仓库介绍
本仓库用于个人技术沉淀与学习归档，包含三大方向：
- 汽车电子基础知识、电路端子、线束标准学习笔记
- CAN总线、DBC数据库、UDS统一诊断协议原理与实操笔记
- Vector工具链 CANoe / vTESTstudio 学习记录
- 前端基础学习源码（HTML/CSS/JavaScript/Vue）
- Python 实现 CAN 报文解析、UDS 简易诊断小工具
- 开发环境配置、软件安装踩坑解决方案

## 目录说明
- `auto-electronic-notes`：汽车电子综合学习笔记
- `can-uds-protocol`：CAN、DBC、UDS 协议详解与案例
- `vector-tools`：CANoe、vTESTstudio Viewer 实操记录
- `front-end-study`：前端学习练习代码与案例
- `python-can-tools`：Python 编写的总线解析、诊断辅助脚本
- `env-config`：IDE 配置、环境搭建、报错解决记录

## 持续更新
日常学习、实操踩坑、协议理解、代码demo 都会持续提交更新，作为个人技术成长知识库。
